# 1. Overview

## 섹션 목적

RMS 시스템의 전체 현황을 한눈에 파악하고, 이슈 디바이스에 신속하게 대응하며, 기간별 데이터 리포트를 조회할 수 있는 섹션이다. 대시보드를 통해 주요 지표를 모니터링하고, Quick Operation으로 즉각적인 원격 제어를 실행한다.

## 페이지 목록

| 순서 | 페이지 | 목적 |
|------|--------|------|
| 1 | [Dashboard (1-depth)](./dashboard-1-depth.md) | RMS 진입 후 첫 화면. 전체 디바이스 현황, 앱 사용량, 재부팅 현황, 성능 임계치 초과 현황, 펌웨어 배포 현황을 한눈에 파악 |
| 2 | [Dashboard (2-depth)](./dashboard-2-depth.md) | 각 위젯 클릭 시 표시되는 상세 팝업. 선택 위젯의 통계 그래프와 디바이스 목록을 제공하여 심층 분석 지원 |
| 3 | [Quick Operation](./quick-operation.md) | 임계치 초과 이슈 디바이스를 한눈에 파악하고 목록에서 Restart 커맨드를 즉시 실행하는 빠른 운영 화면 |
| 4 | [Reports](./reports.md) | 디바이스 로그, 통계 리포트, 장애(Failure) 리포트를 탭별로 조회하고 Excel로 다운로드 |
