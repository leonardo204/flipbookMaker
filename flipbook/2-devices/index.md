# 2. Devices

## 섹션 목적

등록된 셋톱박스 디바이스를 조회·관리하고, 그룹 단위로 묶어 원격 커맨드를 실행하며, VOC 세션 이력을 관리하는 섹션이다. 디바이스 정책(임계값 및 자동 액션)을 설정하여 이슈를 사전에 탐지하고 대응할 수 있도록 지원한다.

## 페이지 목록

| 순서 | 페이지 | 목적 |
|------|--------|------|
| 1 | [Device List](./device-list.md) | 등록된 셋톱박스 목록 조회. 디바이스 등록/수정/삭제 및 원격 커맨드 실행을 제공하는 메인 디바이스 관리 화면 |
| 2 | [Search](./search.md) | Device List에서 최대 3개의 검색 조건을 조합하여 디바이스를 필터링하는 기능 |
| 3 | [Device Group](./device-group.md) | 셋톱박스를 그룹으로 묶어 관리. 그룹 단위로 커맨드 실행 및 디바이스 일괄 관리 |
| 4 | [Command (1)](./command-1.md) | Device List/Device Group에서 선택한 디바이스/그룹에 Device Control 및 App Control 원격 커맨드를 실행하는 화면 |
| 5 | [Command (2)](./command-2.md) | Network Packet Capture, Send Dump, Factory Reset, Firmware Update, Message 등 고급 제어 커맨드 화면 |
| 6 | [VOC Devices](./voc-devices.md) | 셋톱박스 VOC 세션 이력 관리 및 VOC Overview 통계 제공. 신규 VOC 세션 시작 및 이슈 리포트 조회 |
| 7 | [Device Policy](./device-policy.md) | 디바이스 상태/성능 임계값 조건을 정의하고, 조건 충족 시 자동으로 실행될 액션을 설정하는 정책 관리 화면 |
