# 4. Connecting Devices

## 섹션 목적

선택한 기기와 직접 연결하여 실시간 디바이스 상태를 확인하고 원격 제어를 수행하는 섹션이다. Device Control, App Control, Advanced Control 카테고리의 다양한 커맨드를 지원하며, 연결 종료 시 이슈 리포트를 작성한다.

## 페이지 목록

| 순서 | 페이지 | 목적 |
|------|--------|------|
| 1 | [Connecting Devices Policy](./connecting-devices-policy.md) | 기기 연결 팝업 전반에 적용되는 공통 정책(Tooltip, Scroll, Minimize, Apply, Reload 등) 정의 |
| 2 | [Connecting Devices](./connecting-devices.md) | 선택한 기기와 연결하여 Device Info, Device State, Dashboard, Data Usage, Diagnostics를 확인하고 원격 제어를 수행하는 메인 팝업 |
| 3 | [Command - Device Control](./command-device-control.md) | Screen Share, Restart, Shutdown, Standby, Awake, Mute/Unmute, Lock/Unlock 총 7개 디바이스 제어 커맨드 |
| 4 | [Command - App Control](./command-app-control.md) | App List 조회/제어, Install Application, Clear Cache 3개 앱 제어 커맨드 |
| 5 | [Command - Advanced Control](./command-advanced-control.md) | Network Status, Network Packet Capture, Send Dump, Factory Reset, Message, Install Firmware, Control RMS 7개 고급 제어 커맨드 |
| 6 | [Issue Report](./issue-report.md) | 연결 종료 시 표시되는 화면. 사용한 커맨드, 이슈 유형, 이슈 결과를 기록하여 이슈 리포트 완성 |
