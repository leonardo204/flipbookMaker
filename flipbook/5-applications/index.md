# 5. Applications

## 섹션 목적

RMS에 등록된 앱을 관리하고, 대상 기기 그룹에 앱을 설치하며, 앱 관련 정책(임계값, 관리 앱, 화이트리스트/블랙리스트)을 설정하는 섹션이다.

## 페이지 목록

| 순서 | 페이지 | 목적 |
|------|--------|------|
| 1 | [App List](./app-list.md) | RMS에 등록된 앱 목록 조회 및 관리. 앱 업로드, 상세 조회, 삭제 기능 제공. 삭제된 앱은 Deleted App 탭에서 확인 |
| 2 | [App Install](./app-install.md) | 등록된 앱을 대상 기기 그룹에 설치 명령 발행. 설치 진행 상태 조회 및 실패 기기 재시도 기능 제공 |
| 3 | [App Policy](./app-policy.md) | Threshold, Managed App, Whitelist, Blacklist 4개 탭으로 구성된 앱 정책 관리 화면 |
