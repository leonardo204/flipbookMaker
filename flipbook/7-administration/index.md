# 7. Administration

## 섹션 목적

시스템 관리자 계정과 역할(Role)을 관리하고, 이메일 알림 정책을 설정하는 섹션이다. 관리자 등록 승인/거부, 역할별 메뉴 접근 권한 및 커맨드 실행 권한 설정, 알림 이메일 구성을 담당한다.

## 페이지 목록

| 순서 | 페이지 | 목적 |
|------|--------|------|
| 1 | [Administrator List](./administrator-list.md) | 등록된 관리자 목록 조회. 상세 정보 확인, Role Level 변경, 계정 삭제, 신규 관리자 등록 요청 승인/거부 기능 |
| 2 | [Role Setting](./role-setting.md) | 관리자 역할 등록 및 관리. Role Level, 메뉴 접근 권한(Hidden/Read Only/Editable), 디바이스 그룹 접근 권한, Connecting Devices 커맨드 실행 권한 설정 |
| 3 | [Alert Setting](./alert-setting.md) | 이메일 알림 설정. Device Status Alert와 OTT New Version Alert 두 가지 유형 관리 및 Mail Template 설정 |
