# 8. Set-top box UI scenario

## 섹션 목적

셋톱박스(Android 기반)에서 RMS 앱을 통해 상담원과 연결하는 전체 UI 시나리오를 정의하는 섹션이다. 사용자 측 화면 흐름, 팝업 동작, 키 조작 방식, 연결 해제 및 오류 처리를 포함한다.
